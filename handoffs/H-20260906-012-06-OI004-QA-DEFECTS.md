## Context

Chat 07 static QA found two client implementation defects against `docs/UI_TUTORIAL_SPEC.md`.

## Defects

1. Help recap is opened with `HTMLDialogElement.showModal()` in `client/src/main.ts`, but the Tutorial spec requires the help recap to be non-modal and non-blocking.

2. Birth/T7 availability is gated only by `player.financial.representative` in both Tutorial unlock logic and Birth panel button. The spec requires T7 to appear only when Birth is actually available from authoritative gameplay state and says to omit/defer when required authoritative data is unavailable rather than guessing.
