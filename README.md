# INTERGENERATIONAL CONTRACT

Canonical repository for the INTERGENERATIONAL CONTRACT project.

## Repository roles

- `docs/` — canonical project rules, decisions, issues, release and verification state.
- `server/` — authoritative server and engine source.
- `client/` — client implementation.
- `tests/` — shared/integration test assets when applicable.
- `reports/` — current AI Specialist Reports for Chats 01–08.
- `archive/` — superseded or historical material kept for traceability.

## Canonical-source principle

1. Latest explicit user decision.
2. `docs/RULE_LEDGER.md` and other canonical docs.
3. Current verified source code.
4. Tests.
5. AI Specialist Reports.

This repository is intended to be the long-term shared source of truth. Project Sources in ChatGPT should remain lightweight and point to the canonical repo/version.
